# Shark Tank Simulator

Pitch your idea to a panel of AI investors who will not go easy on you. They question you round by round, react to every answer, make offers you can negotiate, and leave you with a sharper pitch.

**Live:** _coming soon_

## Run locally
```bash
npm install
cp .env.example .env.local   # add your Gemini API key
npm run dev
```

## Stack
Next.js 16, TypeScript, Tailwind CSS, Gemini API, Google Cloud Run.

Built at PromptWars (8-Hour Build With AI Hackathon, Pondicherry University).
